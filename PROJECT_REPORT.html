1. Project Overview

The Hydrogen Pipeline Monitor is a full-stack, enterprise-grade web application designed for real-time monitoring, alerting, and compliance management of hydrogen gas distribution pipelines. It simulates an industrial IoT system where sensor data is continuously streamed, analyzed, and visualized through a role-protected dashboard.

The platform serves three distinct user roles — Admin, Manager, and Operator — each with tailored access permissions enforced on both the backend API and the frontend interface.

Key Features

  • Live Sensor Dashboard — Real-time pressure readings with trend charts auto-refreshing every 10 seconds
  • Automated Alert Engine — Backend simulator auto-generates alerts when readings breach safe limits
  • JWT Authentication — Secure login with token-based session management and role enforcement
  • Maintenance Management — Schedule, track, and complete pipeline maintenance tasks
  • Compliance Reports — Generate audit-ready reports covering pressure, alerts, and maintenance metrics
  • User Management — Admin panel to add, edit, change roles, and delete users
  • Redis Caching — Latest sensor readings cached in Redis for sub-millisecond access
  • Docker Infrastructure — PostgreSQL and Redis run via Docker Compose for easy local setup

Data Flow

  1. The sensor simulator runs on the backend server as a background process, inserting realistic readings every 8 seconds for each active sensor.
  2. Values outside safe limits automatically trigger alert records in the database.
  3. The frontend polls the REST API every 10 seconds to refresh the dashboard.
  4. The Redis cache stores the latest reading per sensor for fast retrieval without hitting PostgreSQL on every request.
  5. All API requests carry a JWT Bearer token validated on the backend before any data is returned.

7. Real-Time Features

Sensor Simulator (Backend)

A setInterval-based background job starts automatically when the server boots. Every 8 seconds it:

  1. Queries all active sensors from PostgreSQL
  2. Generates a realistic reading using the sensor's min_safe_value and max_safe_value
  3. Applies a 3% chance of critical spike and 4% chance of low dip to simulate anomalies
  4. Inserts the reading into sensor_readings
  5. Updates the Redis cache with the latest reading per sensor
  6. If the value is outside limits: automatically creates a leak_alert with appropriate severity

Reading Generation Algorithm

function generateReading(min, max) {
  const roll = Math.random();
  if (roll > 0.97) {
    // 3% — critical spike above max
    return { value: max + (max-min) * 0.15, quality: "warning" };
  } else if (roll > 0.93) {
    // 4% — dip below min
    return { value: min - (max-min) * 0.1, quality: "warning" };
  } else {
    // 93% — normal fluctuation within safe range
    const fluctuation = (Math.random() - 0.5) * (max-min) * 0.25;
    return { value: (min+max)/2 + fluctuation, quality: "good" };
  }
}

Frontend Polling

The dashboard auto-refreshes every 10 seconds via setInterval in a React useEffect:

useEffect(() => {
  if (!user) return;
  loadDashboard(); // Immediate load on login
  const interval = setInterval(loadDashboard, 10000); // Refresh every 10s
  return () => clearInterval(interval);
}, [user?.id]);

10. Deployment Guide

Step 1 — Prepare & Push to GitHub

cd "c:\Users\mohan\Music\roshan program\hydrogen-pipeline-monitor"

git init

# Create repo at github.com/new then:
git remote add origin https://github.com/YOUR_USERNAME/hydrogen-pipeline-monitor.git
git branch -M main
git push -u origin main

Step 2 — Cloud Database (Neon.tech — Free)

  1. Go to neon.tech → Create account → New project
  2. Copy the DATABASE_URL connection string (format: postgresql://user:pass@host/db)
  3. Paste schema.sql and seed.sql into the Neon SQL editor and run them
  4. Run set-passwords.js pointed at the Neon DB to set passwords

Step 3 — Cloud Redis (Upstash — Free)

  1. Go to upstash.com → Create account → Create Redis database
  2. Copy the REDIS_URL (format: rediss://...upstash.io:6379)

Step 4 — Backend on Render.com (Free)

  1. Go to render.com → Sign up with GitHub
  2. Click New → Web Service → Connect your repo
  3. Set Root Directory: backend
  4. Set Build Command: npm install && npm run build
  5. Set Start Command: node dist/server.js
  6. Add environment variables: DATABASE_URL, REDIS_URL, JWT_SECRET, NODE_ENV=production
  7. Click Create Web Service

Your backend URL: https://YOUR-APP.onrender.com

Step 5 — Frontend on Vercel (Free)

  1. Go to vercel.com → Sign up with GitHub
  2. Click Add New → Project → Import your repo
  3. Set Root Directory: frontend
  4. Add environment variable: VITE_API_URL = your Render backend URL
  5. Click Deploy

Your live app URL: https://hydrogen-pipeline-monitor.vercel.app

✅ Total Cost: $0 — All services used are on their permanent free tiers.
